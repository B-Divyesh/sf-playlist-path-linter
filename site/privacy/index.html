Policy / 2026-09-06

Privacy and local data

Playlist Path Linter runs on your device. The CLI makes no network requests. The browser worksheet processes playlist text and selected file names in your browser.

Data collection

There are no accounts, cookies, analytics, advertising identifiers, or third-party scripts. The site host may retain ordinary security logs under its infrastructure policy.

Local files

The folder picker passes selected file names to the current browser tab so it can compare paths. It does not read audio contents. The normal worksheet clears when you refresh. The demo uses a separate browser-storage key and clears it when you choose Start for real.
