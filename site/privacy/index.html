Policy / 2026-08-27

Privacy

Playlist Path Linter is local by design. The CLI makes no network requests. The browser worksheet processes playlist text and selected file names in your browser; it does not upload, retain, or share them.

Data collection

There are no accounts, cookies, analytics, advertising identifiers, or third-party scripts. The site’s host may retain ordinary security logs such as an IP address and request time under its infrastructure policy.

Local files

The folder picker exposes file names to the current browser tab so it can compare paths. The website does not read audio contents. Closing or refreshing the page clears worksheet data.
