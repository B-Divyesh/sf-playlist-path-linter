CLI sample

Run the bundled CLI demo

Use the same sample in a temporary workspace. It reports Unicode, case, and missing-path problems, then names the corrected copy.

Open the browser sample →
$ playlist-path-linter demo
warn  unicode_normalization  Beyoncé/.../Halo.flac
warn  case_mismatch          Talk TALK/.../Desire.mp3
error missing_path           Missing/Encore.mp3
Corrected copy: sample.fixed.m3u8

Privacy and scope

What the tool does not do

It does not upload playlists, contact music services, change media tags, or overwrite your source playlist.

The CLI checks date tags in resolved audio files. The browser worksheet checks path text only.

Read the privacy policy →

Single local binary / v0.1.0

Install the command-line tool

Build the Rust binary, point it at a playlist and library root, and save the report with the transfer.

$ cargo install --path crates/playlist-path-linter

$ playlist-path-linter demo

$ playlist-path-linter lint set.m3u8 --root /music --fix set.fixed.m3u8 --json
